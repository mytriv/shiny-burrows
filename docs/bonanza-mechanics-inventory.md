The transferable design lesson is a cycle of clues, route choice, visible excavation and a useful reward. Its effectiveness is an interpretation, not a measured fact about this JAR. Shiny Burrows can test that cycle using its existing gold, ladders, platforms, claws and round boulders. Carry limits, stamina exhaustion, consumable menus, enemy encounters, supernatural dialogue and multiple hazard simulations are not prerequisites for that test.

# Milestone A hotfix — ladder grip while mining

Design before edits,2026-10-23. Scope: fix authoritative grip/movement/contact mining, before B. Preserve fixed ticks, geometry, visuals, mining cadence/durability/regen, automatic downward ladder transitions and platform drops. Existing frame-time failures remain acceptance failures.

Root cause: `motion.ts` requires `!input.moveX` before it resolves X collisions; input intent detaches the mole even if a wall prevents movement. `simulation.ts` correctly resolves movement before contact mining, so this premature gravity changes the mining position.

Retain an acquired valid grip during horizontal intent. Allow normal collision-resolved X movement at fixed Y, without vertical climbing/centering while a horizontal direction is held. After X resolution, query existing ladder support at the actual position: retain grip/zero vertical velocity while supported; release and resume normal gravity only when support is lost. No automatic X motion after input release. A block-breaking tick remains attached because motion already collided with the intact block; the next held tick can enter the opening. Down/platform-drop precedence remains unchanged.

Mining remains after motion at the existing cadence. Where the body straddles two rows, select an actually contacted adjacent solid cell if the usual center-row target is empty; do not strike remotely through open space or change unrelated ground mining. Keep all rule decisions in Core. No new ladder generation path: unchanged `traceLadders` sees the actual resolved motion path only.

Test red/green: both sides, two-hit dirt, interruptions/cooldown/release at destruction, continued displacement and delayed gravity, existing empty exit, no automatic ladder backfill, gold/hard terrain, consecutive walls, straddled rows, ascent/descent/platform drops and no upward excavation. Browser tests must drive keyboard/mouse/multitouch through production input and rendering; fixtures, if needed, are test-only, not shipped state-injection APIs. Run full unit/type/lint/build/browser suite and retain the two known performance failures explicitly if they persist.

## Implemented boundary

Only `src/core/motion.ts` and `src/core/mining.ts` change gameplay. `ladders.ts` and `simulation.ts` remain unchanged after investigation: movement resolves before contact mining, and only the resulting motion path authorizes downward ladder transitions. Acquired grip is checked after collision-resolved X displacement, using the existing ladder proximity rule. Holding a direction can move the mole slightly within that support tolerance; a collision stops it without changing height. Once actual displacement leaves support, the ordinary fixed-step gravity calculation resumes in that tick. This also handles existing empty space without special movement or a teleport.

The adjacent-row mining fallback applies only while gripping, only when the normal center-row target is empty, and only to a solid cell touching the character's leading edge. It cannot excavate upward or reach a remote block. Dirt durability, gold's extra hit, harder strata, upgrades, rewards, cadence and regeneration remain unchanged.

## Regression evidence

The dedicated suite now contains 24 cases, covering both sides, four suspended heights, all three pickaxe powers for dirt, head/feet-only contact, interruptions, regeneration, indestructible walls, gold, hard terrain, actual detachment and consecutive blocks. The old immediate-input-detachment assertion now checks a supported sidestep followed by actual support loss. No tests are disabled.

Three new Chromium tests drive both sides in the real First Burrow through keyboard, mouse and simultaneous touch, including selective release of one of two touch pointers. They climb from the authored shaft, mine the first hit, pause during cooldown, resume until destruction, release and remain suspended, then hold again to leave support and fall onto the adjacent floor. They compare ladders and processed-cell records throughout. The test pauses slightly above the floor so normal collision with that floor does not hide the resumed gravity; it records the actual climbed height and requires exact preservation. No shipped fixture or state-injection hook was added.

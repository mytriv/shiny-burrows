# V3-F controls and mining decisions

V3-F supersedes v0.3 single-hit soil, unrestricted power damage, 12-tick cadence and separate horizontal Dig requirement. Preserve graphics, authored geometry/rewards, gravity, ladders, platform rules, upgrades and infrastructure. No dependencies or further milestones.

- Resolve horizontal movement/collision before automatic contact mining. Only the immediately adjacent facing cell actually touching the collider can be hit. Holding a direction is the sole horizontal mining intent; Dig without Down no longer mines. Explicit Down+Dig retains floor mining before movement, with automatic ladders. Horizontal auto-mining forces a horizontal target even when Down is held without Dig.
- Configurable interval: 24 simulation ticks / 400ms at 60Hz for all strikes. An intact contacted block takes its first hit immediately. Further hits require continuing the same contact. Releasing, reversing, losing contact or switching context cancels the contact timer. Returning to a partially damaged block starts a fresh full interval, preventing rapid taps from bypassing the correction window. Partial integrity stays until the existing 180-idle-tick regeneration.
- Soil/ore-soil integrity 2; compacted/fragile 3; existing gravel 3 and hard 5 retained. Later levels retain higher average hardness and resource values; no gratuitous rebalancing of existing 3/5 strata. Authored ore uses its existing surrounding stratum configuration instead of the old literal 1/2 metadata. Geometry, values and progression stay unchanged. Custom diggable integrity is clamped to >=2. Effective hit count is max(2, ceil(integrity / power)): on an intact block, damage may never reduce remaining integrity below 1. Subsequent strikes use normal power. Regeneration restores the minimum protection as well as integrity.
- All keyboard mappings use physical event.code for down/up. Repeat events never add an action edge. Blur, visibility and pause release browser holds and Core contact state. Controller pause also clears the simulation contact so resuming cannot deliver an old queued hit.
- Keep button styling/layout unchanged; label Dig as Dig ↓. This explicit button emits the existing Down+Dig intent for mouse/touch; keyboard still uses physical S/ArrowDown plus J/X/Space. Walking buttons auto-mine. Distinct blocked-rock feedback uses a short existing-sprite tint/tilt and a message, without replacing graphics.
- Regression gates: exact hit ticks and cancellation, all power tiers, range/rock/wall safety, repeated blocks and immutability, render-FPS grouping, actual alternate-layout CDP key events, blur/visibility/pause, mouse/touch and all pre-existing progression/platform/gravity/browser checks.
